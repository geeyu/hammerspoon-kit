# StayAwake.spoon

防睡眠工具（对标 Amphetamine）。防止系统睡眠 / 显示器睡眠，支持定时恢复。
入口集成在 **控制中心菜单栏 🛠 → 防睡眠**（面板内子页面管理），激活时右上角常驻半透明倒计时条。

## 使用

```lua
-- ~/.hammerspoon/init.lua
hs.loadSpoon("StayAwake"):start()
```

打开方式：菜单栏 🛠 → 控制中心 → 「防睡眠」，面板内打开管理子页面：

| 区块 | 功能 |
| ------ | ------ |
| 状态卡 | 当前状态（保持清醒中 剩余时间 / 系统正常睡眠）+ 当前模式，秒级倒计时 |
| 防睡眠模式 | 允许息屏（仅防系统睡眠）/ 屏幕常亮（防系统+显示器睡眠） |
| 保持清醒 | 永久 / 1-24 小时按钮组 / 5-90 分钟按钮组 |
| 直到某个时间点 | 输入 `yyyy-MM-dd HH:mm:ss`（秒可省略），到点自动恢复 |
| 关闭防睡眠 | 立即恢复系统正常睡眠 |

每次操作即时生效，状态卡实时刷新；"← 返回"回到控制中心聚合页。

## 常驻倒计时条

启用防睡眠后，屏幕右上角（菜单栏下方）常驻半透明倒计时条：

- 定时/直到会话：每秒刷新剩余时间（如 `保持清醒中（剩余 1:02:05）`）
- 永久会话：显示 `保持清醒中（无限期）`
- 会话结束自动消失

## 数据

- 配置：`~/.hammerspoon/data/StayAwake/settings.json`（记住上次的模式）
- HTTP API：`/stayawake/api/state`（状态）、`/stayawake/api/action`（动作）、`/stayawake/view/`（子页面静态）

## 常见问题

- **"直到"输入格式**：`2026-08-01 18:30:00`，秒可省略；时间已过会拒绝并提示。
- **重载后状态**：Hammerspoon 重载（Cmd+Ctrl+Alt+R）后恢复未激活状态，仅保留上次的模式设置。
